## 📌 Repository Overview

This repository hosts the official submission scaffold and documentation for **Team SANKALP** at **Hackwave 3.0 (Indore)**.

Our product interpretation is **India Impact Graph**: an evidence-first system that converts macroeconomic events into an interactive dependency graph and calculates a transparent, receipt-backed monthly rupee impact range on an Indian household's budget.

The complete project architecture, technical specifications, data schemas, CSV templates, and future implementation scaffold are located in the [`india-impact-graph/`](india-impact-graph/) directory.

## 💡 The Four Core USPs

1. **Receipt-Backed Numbers:** Every number on screen has a clickable citation revealing source, table, year, unit, and formula. Missing values show *"Data not available"* — zero AI hallucinations.
2. **Persona Impact Card:** Converts abstract economic percentages into a monthly rupee spending range (e.g., +₹190 to +₹310/month) for State $\times$ Sector $\times$ Expenditure Class archetypes (e.g., MP Rural Middle-Class).
3. **News Consensus Meter (P1):** Compares up to 3 saved news articles per event, highlighting shared facts and reporting discrepancies.
4. **AI-Off Proof (P1):** An interactive UI toggle that completely disables the LLM. All graph structures and calculated rupee amounts remain 100% identical.

> **Golden Rule:**  
> *"AI reads and explains. Verified data and deterministic formulas calculate the numbers."*
